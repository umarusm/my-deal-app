USM VIP PORTAL Android WebView project

Build requirements: JDK 17, Gradle 8.9, Android SDK platform 35 and build-tools 35.0.0.
GitHub Actions workflow is supplied separately in the instructions.

The HTML is packaged locally in app/src/main/assets/index.html.
This is a local demo build. Subscription/payment state is stored on this device only.
Do not use the client-side admin password or local payment approval for production.
